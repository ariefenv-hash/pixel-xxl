# Pixel XXL · Web

> 由 Scratch 工程 `Pixel.XL.0827.html`（TurboWarp 打包，6,162 块积木）**原生重写**的
> Material You「手机操作系统模拟器」。纯 ES Modules 多文件架构，零构建、零框架、零二进制素材。

**在线体验：https://ariefenv-hash.github.io/pixel-xxl/**

这不是积木块→JS 的机械转换，而是按反编译分析报告逐条还原机制的全新实现：
所有布局参数、手势阈值、动画曲线、状态机路由均取自对原工程 3,012 行反编译伪代码的逐脚本核对。

## 功能总览

| 子系统 | 忠实还原的机制 |
| --- | --- |
| 开机 | 启动屏 → 174 帧程序化开机动画（30fps）→ 预渲染/取色门控 → 三页引导（视差入场：ghost 100→0、云母模糊 7→0、尺寸插值） |
| 桌面 | 双页图标栅格（页宽 324、越界阻尼 ÷5、阈值 -50/-274、回弹 /8）、当前页图标 ×0.7 向心、动态时钟大件（时/分/秒针实时旋转） |
| 手势 | 底部返回热区 y<-320、上滑进后台（起手 y<-342、过 -300 判入）、抽屉起手带 -280<y<-200（开合阈值 ±50） |
| All Apps | 自 -695 滑入、越 0 段 ÷10 软化、按进度耦合壁纸模糊（0→16 级）、返回/锁屏/进应用一次性整落 |
| 多任务 | 卡片指数布局公式 `x = 200 + 90·e^(0.001·((n-1)·(-160)+后台x))`、拖动 ×1.5 跟手、上滑移除、点击回前台 |
| 应用窗口 | 图标→窗口 FLIP 变焦开合、**曲线风格 0（指数趋近）/ 1（分段缓动）双套可切**、子页推拉（master x→-100 亮度 -30% ↔ detail 自 +100 滑入） |
| md3e 返回柄 | 右缘起手（x>120）拖拽、拖入 x<80 预告变形、松手 x<140 提交、否则弹回 |
| Monet 取色 | 壁纸像素 → average/k-means 基色 → light/dark tonal palette（键 50~900，极端亮度饱和度 ×0.8）→ 亮度模式（100/500/600/800）单变量切全 UI tone |
| 锁屏 | A/D 键 + 电源键，AOD 大钟 + 解锁涟漪 |
| 音效 | WebAudio 合成开机和弦/解锁滴答；2 首 chiptune 内置曲实时音序合成（原 MP3 涉版权不入库） |

## 内置应用（11 个，对应原工程 11 次「克隆应用」）

- **计算器** —— 完整四则运算，键位坐标 1:1 还原（行 y=-80/-150/-220/-290、列 ±105/±35、= 在 (105,-255)、按下态缩放 0.8）
- **时钟** —— 大表盘 + 数字钟 + 可用秒表；桌面大件与应用同源
- **music** —— 播放列表（2 首）+ 进度条（忠实行程公式 x = AppX-125+(t/len)×125）+ 播放/暂停/结束自停
- **设置** —— 状态机 0 → 1-{关于本机} → 2-{彩蛋}；彩蛋页内置曲线风格开关（对应原工程两个顶层调试开关）
- **个性化** —— 7 张程序化壁纸两页选择 + 亮度模式四档，选中即广播「壁纸」重取色
- **相册 / 商店 / 通知 / 视频 / 电话 / bilibili / 时钟** —— 真实内容页（相册可设壁纸、商店可跳转应用、通知联动播放器、视频为生成式演示影片、电话为拨号盘、bilibili 为外链卡）

## 运行

零依赖零构建，任意静态服务器即可：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

键盘：`A` 锁屏 / `D` 解锁 / `←→` 翻页 / `Esc` 返回；全部手势亦可用鼠标/触屏完成。

## 与原工程的差异（刻意取舍）

1. **素材全程序化**：原工程 52.8MB 素材（5 张照片壁纸占 30+MB）改为画布绘制，仓库 <200KB。
2. **音乐为合成替代**：原 2 首 MP3（fripSide / 刀酱）涉及版权，以同氛围 chiptune 实时合成替代，播放器语义完整保留。
3. **锁屏/AOD 为补全视觉**：原工程锁屏仅冻结状态（a/d 键），此处补全 AOD 视觉层。
4. **61 帧预渲染换肤 → 实时 FLIP**：Web 下 CSS 变焦动画零卡顿，无需预计算帧序列。
5. **计算器真实可算**：原工程反编译未见运算逻辑（按键仅动画），按「真实网页项目」要求补全。
6. **时钟大件 y 170→200**：为避免与首行图标视觉重叠的 30 单位微调。
